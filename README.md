# Blug Forum

Befintligt skolprojekt: REST-backend med Spring Boot, sessionsautentisering och PostgreSQL. Blug tillhandahåller frontend separat; den befintliga Thymeleaf-dashboarden finns kvar.

- [Windows-start, tester, API, behörigheter, CSRF, provisionering och backup](docs/fortsattningsguide.md)
- [Individuell säkerhets- och integritetsanalys](docs/individuell-analys-sakerhet-integritet.md)

Testad utveckling integreras i `release` via separata feature-brancher. Lärarens exakta endpointkontrakt och faktisk frontendintegration återstår att verifiera.
